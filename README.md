# Treasure Collector Simulator 🏆

A Unity-based Treasure Collector game where player explore a dungeon environment, collect treasures to win.

## Features

- VR/XR Interaction Toolkit integration
- Collectible treasures (Coins, Gold Bars, Diamonds)
- Real-time score tracking
- Treasure chest unlock system
- Win screen upon successful treasure collection
- Low-poly dungeon environment
- XR Device Simulator support for testing without a VR headset

## Technologies Used

- Unity 6
- C#
- XR Interaction Toolkit
- Input System
- XR Device Simulator

## Gameplay

1. Explore the dungeon.
2. Collect all available treasures:
   - Coin
   - Gold Bar
   - Diamond
3. Increase your score by collecting treasures.
4. Reach the treasure chest.
5. Unlock the chest and win the game.

## Controls (XR Device Simulator)

| Action | Key |
|----------|----------|
| Move | W A S D |
| Look Around | Mouse |
| Controller Mode | T |
| Hand Mode | Y |
| Up/Down | Q / E |
| Toggle XR Input | Tab |
